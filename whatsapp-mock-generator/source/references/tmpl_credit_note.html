⚠️ Red PDF Icon vs Standard Pink Icon

Use the correct document icon style based on document type:

Red pill icon (background:#E53935) — for credit notes and return documents. Rendered as a solid red rounded rectangle with white "PDF" text (8px bold). Signals a financial reversal document visually.

Standard pink/grey doc SVG icon (background:#F06292 with folded-corner SVG) — for invoices and dispatch notes. Never use the red icon for standard invoices.
