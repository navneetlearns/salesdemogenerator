Admin Report — Sales Team Activity

tmpl_admin_report · Desktop web UI · app.zotok.ai

When to Use

Use when a journey step shows head office or area management reviewing team-wide field performance — check-ins, orders, SKUs, and payment collections across all sales executives, filterable by date range.

Standard Columns

  • S.No — row number, grey text
  • Salesperson Name — blue clickable link
  • Customers — unique customer count
  • CheckIns — total check-in events
  • Number of Orders — orders placed
  • Total SKU — line items across orders
  • Order Value — green when positive
  • Payments Collected by UPI
  • Payments Collected by Cash

Checklist

  • Browser chrome: macOS traffic lights + URL bar
  • URL always shows app.zotok.ai
  • Download button: #2196F3 blue
  • Date range filter with calendar icon and ▾ dropdown caret
  • Pagination: prev/next chevrons + "1 – N of N" + page size pill
  • Footer totals row with sub-labels below each total
  • No sidebar navigation on this screen — report fills full card width
  • Do not add left icon rail or sub-nav menu to report screens
