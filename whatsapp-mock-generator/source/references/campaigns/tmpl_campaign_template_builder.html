When to Use

Show this screen when depicting how an admin creates a custom WhatsApp message template from scratch. This is under Settings → WhatsApp, not within the campaign wizard.

Template Sections (Form)

  • Name — snake_case, max 88 chars (e.g. "summer_deal")
  • Category — dropdown: Utility / Marketing / Authentication
  • Language — dropdown: English / Hindi / Marathi / etc.
  • Header — type selector: None / Text / Image / Video / Document / Location. Image = upload box
  • Body — rich text area with B/I/S/emoji toolbar + Add Variable. Char counter: 281/1024
  • Footer — plain text, max 60 chars, no emojis
  • Buttons — Add Button → URL type or Quick Reply type

Meta Compliance (Template Rules)

  • Footer: plain text only, max 60 chars, no emojis, no variables
  • Body: no divider lines, no tables, no HTML
  • Header: ONE type only — Image OR Text OR Document, never combined
  • Buttons: ONE type per template — all URL or all Quick Reply
  • Warn on submit: template goes to Meta for verification
  • Variables cannot be consecutive ({{1}}{{2}}) or start/end the body
