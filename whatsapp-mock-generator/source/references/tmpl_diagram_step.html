Critical CSS Overrides
/* By default, .step-section.active uses display:flex. Diagram steps need display:block so .screen-wrap can expand to full step width. Use the specific #step-N ID to avoid affecting any other step in the file. */ /* Override 1 — display:block when active */ #step-N.active { display: block; } /* Override 2 — screen-wrap fills full width, centred, max 900px */ #step-N .screen-wrap { width: 100%; max-width: 900px; margin: 0 auto; } /* Override 3 — screen-desc at full width (not default 375px) */ #step-N .screen-desc { width: 100%; }
Why these overrides are necessary: The default .step-section.active { display:flex; } rule centres phone frames side by side. Removing display:flex at the step level allows the inner .screen-wrap to stretch to the full content area width, giving the diagram room to breathe at up to 900px.
Embedding Images
✓
PNG (recommended) — base64 encoded, self-contained, no external request:
<img src="data:image/png;base64,..." style="width:100%;height:auto;display:block;" />
✓
Inline SVG — vector quality, no size loss at any zoom:
<svg width="100%" height="auto" viewBox="0 0 W H">...</svg>
Caution: SVGs over 1 MB slow page load and inflate file size significantly.
!
Converting SVG to PNG on macOS — use sips:
sips -s format png input.svg --out output.png
The resulting PNG is usually 40–60% smaller than the embedded SVG string. Always prefer PNG for large diagrams.
