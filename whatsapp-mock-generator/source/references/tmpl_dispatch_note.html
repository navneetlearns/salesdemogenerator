Dispatch vs Invoice — Document Icon

Both Dispatch Note and Invoice use the Document header type. The icon style identifies the document context:

Standard pink/grey doc SVG icon — for invoices and dispatch notes. This is the default document icon in WhatsApp templates. Use it for all standard shipping and billing documents.

Red pill "PDF" icon (background:#E53935) — reserved exclusively for credit notes and return documents. Never use the red icon for dispatch notes or invoices — it signals a financial reversal.
