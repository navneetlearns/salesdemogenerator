Pattern Overview
Type
Session Message  — ZoAi responds within the 24hr window; no template approval needed for Bubble 3
Bubble 1
Utility Template  — requires Meta approval; sent as outbound business-initiated message
Bubble 2
Dealer taps Quick Reply button → WhatsApp sends that button label as a text message
Bubble 3
ZoAi Session  — ZoAi detects the keyword intent, responds with document/link/data within 24hr window
Trigger
Dealer taps Quick Reply → sends keyword → ZoAi intent detection → responds within 24hr window
Use Cases
Ledger download, document on demand, contextual follow-ups, AI-driven guided journeys
When to Use This Pattern
Template has a Quick Reply button that triggers a follow-up action. The button label becomes the user's reply text, which ZoAi listens for and matches to an intent.
ZoAi responds with a document, link, or structured data. The response is a session message — no new template approval needed as long as the dealer replied within the last 24 hours.
The response must arrive within the 24hr session window. If the window has expired, ZoAi must use a pre-approved template to re-engage the dealer first.
Use for contextual follow-ups — e.g., dealer taps "Know Product" → ZoAi sends a catalog link; dealer taps "Download Ledger" → ZoAi sends the ledger PDF; dealer taps "Raise an Issue" → ZoAi opens a ticket form.
3-Bubble Structure
1
Received Template (Business-Initiated)
A pre-approved WhatsApp Business template sent by ZoTok. Contains a Quick Reply button (e.g., "Download Ledger"). Requires Meta approval. Aligned left in the chat (receiver bubble style). Sender name shown above as "Zotok AI".
2
Sent Reply (Dealer Tap)
When the dealer taps a Quick Reply button, WhatsApp sends that button's label text as a plain sent message. Aligned right (sender bubble, background #DCF8C6). Opens the 24hr session window — ZoAi can now respond freely without a new template.
3
Received ZoAi Session Response
ZoAi detects the intent from the Quick Reply text and responds with the appropriate content — a document, a URL button, a form link, or a plain message. This is a session message within the 24hr window: no Meta approval needed. Aligned left (receiver bubble). Can include a document header + CTA button.
Auto-Scroll Setup — Critical Implementation Note

When a screen uses this 3-bubble pattern, the chat area must scroll to the bottom so ZoAi's response (Bubble 3) is visible on load — otherwise the user only sees the initial template and the sent reply, and the ZoAi response is hidden below the fold.

Follow these two steps in the journey HTML:

Step A — Add an ID to the chat area element for that screen:

<div class="chat-area" id="s3s2-chat">

Step B — In showDesktopStep(n), add a scroll after the scale call:

if (n === 3) {
  setTimeout(scaleStep3Desktop, 10);
  setTimeout(function() {
    var c = document.getElementById('s3s2-chat');
    if (c) c.scrollTop = c.scrollHeight;
  }, 80);
}

Meta Compliance
✓ Bubble 3 (ZoAi response) is a session message — no Meta template approval required
✓ Bubble 3 may include a document header, body text, and CTA buttons freely — session messages are not restricted by template rules
✓ Bubble 1 (the initial template with Quick Reply) DOES require Meta approval — submit it in the template manager before using
✓ Quick Reply labels on Bubble 1: max 3 buttons, 25 chars each, no emojis in button titles
✓ "Download Ledger" = 15 chars ✓ · "View Credit Note" = 16 chars ✓ · both under 25 ✓
