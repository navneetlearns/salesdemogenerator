⚠ Check-Out order field shows "—" if no order was placed during the visit — handle gracefully in ZoAi response logic
Relationship to Other Templates
Check-In → Activity Timeline: Each ZoAi check-in confirmation is automatically logged as an event on the field ops activity timeline (tmpl_fieldops_activity_timeline.html). The timeline groups all events (check-in, orders, notes) under a retailer header card for that visit.
Not the same as Clock-In: tmpl_clock_in.html covers SE attendance — logging arrival at office or field start of day. Check-In/Out is per-retailer visit tracking within the field day. Both use @zoai commands in the same group.
