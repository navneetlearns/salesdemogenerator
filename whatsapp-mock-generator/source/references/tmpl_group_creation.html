Group Creation Flow — 3 Screens
StepScreenAdmin Action
1 · New Group Setup — Name Entry Tap "+ New Group" from WhatsApp chats list. Enter group name (max 25 chars). Optionally add a group icon via camera/gallery. Tap ✓ to proceed.
2 · Add Participants Setup — Contact Picker Search contacts. Tap to select members — selected contacts appear as chips at the top. Always include ZoAi Agent. Tap ✓ to create.
3 · Group Created Group Chat System message: "You created group '…'". System message: "You added [names]". ZoAi sends welcome message automatically.

Checklist
✓ Setup screens use WHITE status bar and WHITE top bar — same rule as Group Chat.
✓ "Cancel" and "Back" links use iOS blue #007AFF.
✓ Confirm button is a green circle with white ✓ — not a text button.
✓ Group name field has brand-color underline (2px) in active state.
✓ Group name max 25 characters — show counter "NN/25".
✓ ZoAi Agent must always be added as a participant — first in the list.
✓ Avatar initials are 2 letters from the contact name, on colored circle.
✓ Selected contacts shown as colored chips in the chips row.
✓ Body background is #f5f5f5 — NOT the WhatsApp doodle background (that's chat-only).
✗ Do NOT show the chat area, input bar, or message bubbles on setup screens.
✗ Do NOT use the dark green #075E54 top bar — that is DM screens only.
⚠ After group creation, immediately show a Group Chat screen (white top bar) with system messages and ZoAi welcome.
ZoAi Auto-Welcome Message:
When the group is created and ZoAi Agent is added as a participant, ZoAi automatically sends a welcome message in the group. This message should:
— Use plain session text (no template, no buttons)
— Greet the team and describe the group's purpose
— List the key commands available (e.g. @zoai clock-in, @zoai check-in)
— Sender name shown as "ZoAi 🤖" in teal (#00897B) inside the bubble
