Card Anatomy — Two-Layer Structure
LayerElementSpec
Outer Card Shape White #FFFFFF rounded rectangle — border-radius: 14px
Shadow 0 6px 20px rgba(0,0,0,.08), 0 2px 6px rgba(0,0,0,.05) — two-layer soft shadow
Sticky Note Position Absolute — left: 7px; right: 7px; bottom: 7px. 7px margin from card on left, right, and bottom edges.
Shape border-radius: 10px on all corners. Shadow: 0 -2px 8px rgba(0,0,0,.07)
Height ratio ≈70% of card height. Card 158px → sticky 112px. White gap at top ≈ 39px.
Pushpin Position Centered on sticky top edge — position: absolute; top: -12px; left: 50%; transform: translateX(-50%) relative to sticky.
Shape 22px circle. Radial gradient: highlight (#ff9a9a) at 37% 32% → mid red (#e83535) → dark (#9e0c0c). Creates 3D dome illusion.
Stem ::after pseudo — 4×8px, bottom: -7px, gradient #aaa → #777, rounded bottom. Simulates pin shaft.
Number Font font-family: 'Caveat', 'Bradley Hand', cursive — Google Fonts "Caveat" (weight 700). Import: https://fonts.googleapis.com/css2?family=Caveat:wght@700
Style 23px (preview) / 36–48px (production). Color #1a1a2a. Zero line-height, display: block.
Icon Position Absolute in white area of card — top: 10px; right: 10px. 16px preview / 24–28px production.
Style Line icon, stroke #333, opacity 0.75. Stroke-width 1.4–1.5. No fill. Cycles across 4 icons per row.
Title Typography 11–13px (production: 14–16px), font-weight 700, color #111. Sits below number with 4–6px gap.
Description Typography 9–10px (production: 12–13px), color #555, line-height 1.4. 2px gap below title.

Checklist
✓ Google Font "Caveat" imported — numbers use handwriting style, weight 700.
✓ Sticky note is 7–10px inset from card on all sides (left, right, bottom) — never edge-to-edge.
✓ Pushpin uses radial gradient with highlight at 37% 32% for realistic 3D dome appearance.
✓ Pushpin stem rendered with ::after pseudo — no extra element needed.
✓ Card shadow uses TWO layers — a soft wide shadow + a tighter close shadow.
✓ Colors assigned in fixed sequence (01 mint → 08 pink) — never randomize.
✓ Icon cycles by column position — same icon repeats at same column in row 2.
✓ Heading uses system sans-serif (not Caveat) — only numbers use the handwriting font.
✓ Section background #ECEFF4 — very light blue-grey, NOT pure white or mid-grey.
✓ Sticky height is ~70% of total card height — maintain this ratio when scaling.
✗ Do NOT add border or outline to cards — the shadow defines the card boundary.
✗ Do NOT use more than 8 cards in a single grid — split into multiple grids if needed.
⚠ Description text should be ONE short line at production scale. Avoid wrapping beyond 2 lines.
ℹ For fewer than 8 items, use 4-col row 1 only, or use a 2×N layout. Never leave an empty card slot.
When to use this pattern:
Use the sticky note bullet grid for capability overviews — when presenting ZoAi features, product modules, or service offerings to a client. Ideal for the "ZoAi Capabilities" panel in a journey file (Page 2 equivalent). Each card = one distinct capability. Keep titles to 2–3 words and descriptions to one punchy line. Maximum 8 capabilities per grid.
⚠ Font availability:
"Caveat" is a Google Font and requires an internet connection to load. Always include the <link> import in the <head>. Fallbacks: 'Bradley Hand' (macOS), 'Brush Script MT' (Windows), then generic cursive. Test in Chrome without internet to verify fallback appearance before client demos.
