Auto-Scroll Pattern
The timeline should default-scroll to the bottom so the latest events are visible without user interaction. Add this to the goTo() function for the step containing this screen:
// In goTo() — after showing the step if (n === N) { requestAnimationFrame(() => { const body = document.querySelector('#step-N .act-body'); if (body) body.scrollTop = body.scrollHeight; }); }
