Form title pill: The grey pill at the top (e.g., "Adityacementsforms") is the form's display name — set in ZoTok's form builder. It replaces the browser URL bar as the primary identifier since the WebView hides the full URL. Keep it short and recognizable to the end user.
ZoTok Integration: On Submit → ZoTok captures form response → sends confirmation template message to visitor's WhatsApp number → optionally notifies admin/front desk via WhatsApp or dashboard notification. Form URL passed as CTA button in a template: https://forms.zotok.ai/{form_id}?wa={{1}}
