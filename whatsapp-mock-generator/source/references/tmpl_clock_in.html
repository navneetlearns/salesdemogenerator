Clock-In Sequence — Message Flow
#SenderMessage TypeContent
1 Sales Executive (You) Location Share Live location pin from current position — map thumbnail + location name + "Live Location" sub-label. Sent BEFORE the command.
2 Sales Executive (You) Reply to location + text Quotes message #1 (location), then sends @zoai clock-in as the body text. The reply links the location proof to the command.
3 ZoAi 🤖 Confirmation text "Clocked In ✅" followed by 4 detail lines: Time, Location, Date, Name (with role). Plain session text, no buttons.

✓ Command is @zoai clock-in — hyphenated, lowercase. Not "clock in" or "clockin".
✓ Reply quote border color is #2E7D32 (self-reply green) — not ZoAi teal.
✓ ZoAi response sender name: "ZoAi 🤖" in #00897B, inside receiver bubble.
✓ ZoAi response has 4 detail lines: Time, Location, Date, Name.
✓ ZoAi response timestamp is +1 minute from command time.
✓ Group top bar is WHITE — dark text, iOS blue back arrow, dark action icons.
✓ Battery shown as number in box ("86") — iOS 16+ style for group screens.
✗ Do NOT add buttons to the ZoAi confirmation — group messages are plain text only.
✗ Do NOT use dark green #075E54 top bar — that is DM only.
⚠ Both Screen A and Screen B carry forward the sender bubble from the previous state — Screen B repeats the @zoai command bubble for conversation continuity.
ZoAi Field Ops Command Reference:
All ZoAi commands follow the pattern @zoai <action> sent in the group.

@zoai clock-in — Mark day start attendance (with location)
@zoai clock-out — Mark day end attendance (with location)
@zoai check-in — Check in at a retailer visit location
@zoai check-out — Check out from retailer visit
@zoai order — Start order capture flow
@zoai report — Get day's activity summary

Always use hyphens in command names. Always quote a relevant location or context message before sending the command.
Why location-first, then command?
WhatsApp's native location share provides geo-verified proof of attendance — it captures GPS coordinates, address, and timestamp. By quoting the location in the @zoai command, ZoAi can extract and store both the time and verified location in one atomic action. This prevents manual entry and ensures audit-grade attendance records.
